{# The delegation calendar's cell, and the box you type overtime into. Lives in its own file because the same calendar is drawn twice — on the standalone Delegation screen and on the By delegator tab of a run. Two copies of this markup is two places for the cell contract to drift, and the one nobody edits is the one that goes wrong. Overtime is charged to the delegator only. Nothing here reads or writes a coach's commission, which is why every peso typed into this box lands in the margin rather than needing to be netted off somewhere else. #} {% macro cell(c, matrix, editable, rid, back) %} {%- set bl = [] -%} {%- for b in c.bookings -%} {%- set _ = bl.append({'id': b.id, 'ref': b.booking_ref or '', 'coach': b.coach or b.staff_raw or '—', 'h': (b.ot_hours|string if b.ot_hours else ''), 'r': (b.ot_rate|string if b.ot_rate is not none else '')}) -%} {%- endfor -%} {%- set label = matrix.codes.get(c.coach, '?') ~ ('×' ~ c.n if c.n > 1 else '') -%} {%- set tip -%} {% for b in c.bookings %}{{ b.coach or b.staff_raw }} · {{ b.booking_ref }}{% if b.ot_hours %} · {{ b.ot_hours|trim0 }} hr overtime{% endif %}{{ ' · ' if not loop.last }}{% endfor %} {%- endset -%} {% if editable %} {% else %} {{ label }} {%- if c.ot_hours %}+{{ c.ot_hours|trim0 }}{% endif -%} {% endif %} {% endmacro %} {% macro popover(rid, back, default_rate, invoiced=False) %}
Log overtime
{% if invoiced %}

This month is already invoiced. Saving updates the charge — you will need to re-issue it or credit the difference.

{% endif %}

Blank rate uses {{ peso(default_rate) }}/hr. Set hours to 0 to remove it.

{% endmacro %}
